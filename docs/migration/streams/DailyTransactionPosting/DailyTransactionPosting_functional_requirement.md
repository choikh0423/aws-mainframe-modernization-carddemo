# S-11 DailyTransactionPosting — functional requirements

The business sign-off oracle for the stream. Every requirement is traceable to the COBOL/JCL source and
covered by at least one automated test in
`migration/carddemo/backend/src/test/java/com/carddemo/batch/posttran/`.

Notation: *daily transaction* = one DALYTRAN record; *amount* = `DALYTRAN-AMT`; *reason* = the 4-digit
validation failure code written to the reject trailer.
