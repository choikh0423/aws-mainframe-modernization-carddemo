Business Flow Analysis

1.1 Business Context

  • What: A five-job monthly batch stream that (1) closes CICS VSAM files, (2) reads every Transaction Category Balance record, looks up the account’s disclosure group interest rate, computes monthly interest as (TRAN-CAT-BAL × DIS-INT-RATE) / 1200, and writes system-generated interest transactions to a SYSTRAN GDG, (3) sort-merges the daily transaction backup with the new interest transactions and reloads the combined result to the TRANSACT VSAM master, (4) pauses for VSAM buffer flush, and (5) reopens CICS files for online access.
  • Who: Upstream: the Daily Transaction Posting batch (POSTTRAN/CBTRN02C) populates the TCATBALF and ACCTDATA files consumed here. Downstream: the combined TRANSACT VSAM feeds the Transaction Report (TRANREPT/CBTRN03C) and Statement Generation (CREASTMT/CBSTM03A) jobs.
  • When: Runs monthly at end of billing cycle, after the last daily POSTTRAN run for the month.
  • Why: Regulatory and business requirement — interest must be computed and applied to account balances each billing cycle. System-generated interest transactions must be merged into the transaction ledger for statement accuracy and audit trail.
  • Outcome: Account balances updated with accrued interest; TRANSACT VSAM contains both customer-originated and system-generated interest transactions; cycle accumulators (CYC-CREDIT/CYC-DEBIT) reset to zero.

1.3 Business Rules Applied in This Process

Rule IDDescriptionApplied AtException Handling
BR-001Interest is calculated per transaction category balance record: monthly_interest = (TRAN-CAT-BAL × DIS-INT-RATE) / 12001300-COMPUTE-INTERESTN/A — standard computation
BR-002If the disclosure group record is not found (status ‘23’), fall back to the ‘DEFAULT’ group code for interest rate lookup1200-GET-INTEREST-RATE / 1200-A-GET-DEFAULT-INT-RATEABEND if default group also not found
BR-003Interest is only computed if DIS-INT-RATE ≠ 0; zero-rate categories are skippedMain loop (line 214)No transaction generated for zero-rate categories
BR-004System-generated interest transactions are written with type code ‘01’ and category code ‘05’ (hardcoded), source ‘System’1300-B-WRITE-TXN/A
BR-005When processing moves to a new account, accumulated total interest is added to ACCT-CURR-BAL, and cycle accumulators (CYC-CREDIT, CYC-DEBIT) are reset to zero1050-UPDATE-ACCOUNTABEND on REWRITE failure
BR-006Transaction IDs are generated as PARM-DATE || WS-TRANID-SUFFIX (10-char date + 6-digit sequence)1300-B-WRITE-TXN/A

BR-008After sort-merge, IDCAMS REPRO loads the combined sorted file into the TRANSACT VSAM KSDS masterCOMBTRAN STEP10 (IDCAMS)IDCAMS returns non-zero on error

2.2 Technical Flow Diagram – Detailed (Step-by-Step)

  === Job 1: CLOSEFIL ===
  STEP: CLCIFIL  EXEC PGM=SDSF
    Via ISFIN DD instream:
      /F CICSAWSA,'CEMT SET FIL(TRANSACT ) CLO'
      /F CICSAWSA,'CEMT SET FIL(CCXREF   ) CLO'
      /F CICSAWSA,'CEMT SET FIL(ACCTDAT  ) CLO'
      /F CICSAWSA,'CEMT SET FIL(CXACAIX  ) CLO'
      /F CICSAWSA,'CEMT SET FIL(USRSEC   ) CLO'

  === Job 2: INTCALC ===
  STEP15: EXEC PGM=CBACT04C,PARM='2022071800'
    INPUTS:
      - TCATBALF: AWS.M2.CARDDEMO.TCATBALF.VSAM.KSDS  (indexed seq read)
      - XREFFILE: AWS.M2.CARDDEMO.CARDXREF.VSAM.KSDS  (keyed random read)
      - XREFFIL1: AWS.M2.CARDDEMO.CARDXREF.VSAM.AIX.PATH (alt index)
      - ACCTFILE: AWS.M2.CARDDEMO.ACCTDATA.VSAM.KSDS  (keyed random I-O)
      - DISCGRP:  AWS.M2.CARDDEMO.DISCGRP.VSAM.KSDS   (keyed random read)
    OUTPUTS:
      - TRANSACT: AWS.M2.CARDDEMO.SYSTRAN(+1)          (sequential output)

    PROCESSING:
      1. Open all 5 files (ABEND if any open fails)
      2. READ TCATBAL-FILE sequentially until EOF
         For each TRAN-CAT-BAL-RECORD:
         a. Increment WS-RECORD-COUNT
         b. If TRANCAT-ACCT-ID changed from previous:
            - If not first record: PERFORM 1050-UPDATE-ACCOUNT
              (ADD WS-TOTAL-INT to ACCT-CURR-BAL, reset CYC accums,
               REWRITE account record)
            - Reset WS-TOTAL-INT to 0
            - Read Account Master by ACCT-ID (1100-GET-ACCT-DATA)
            - Read XREF by alternate key ACCT-ID (1110-GET-XREF-DATA)
         c. Build DISCGRP key from ACCT-GROUP-ID + TRANCAT-CD + TYPE-CD
         d. PERFORM 1200-GET-INTEREST-RATE
            - If status '23' (not found): retry with 'DEFAULT' group
         e. If DIS-INT-RATE ≠ 0:
            - PERFORM 1300-COMPUTE-INTEREST:
              monthly_int = (TRAN-CAT-BAL * DIS-INT-RATE) / 1200
              ADD to WS-TOTAL-INT
              PERFORM 1300-B-WRITE-TX (write interest txn to SYSTRAN)
            - PERFORM 1400-COMPUTE-FEES (stub — not implemented)
      3. After EOF: PERFORM 1050-UPDATE-ACCOUNT for last account
      4. Close all files
      5. Display counts
      6. GOBACK (RC=0)

  === Job 3: COMBTRAN ===
  STEP05R: EXEC PGM=SORT
    SORTIN:  AWS.M2.CARDDEMO.TRANSACT.BKUP(0)
             AWS.M2.CARDDEMO.SYSTRAN(0)
    SYMNAMES: TRAN-ID,1,16,CH
    SYSIN:    SORT FIELDS=(TRAN-ID,A)
    SORTOUT:  AWS.M2.CARDDEMO.TRANSACT.COMBINED(+1)
              (NEW,CATLG,DELETE), DCB=(*.SORTIN)

  STEP10:  EXEC PGM=IDCAMS
    REPRO INFILE(TRANSACT) OUTFILE(TRANVSAM)
      TRANSACT: AWS.M2.CARDDEMO.TRANSACT.COMBINED(+1)
      TRANVSAM: AWS.M2.CARDDEMO.TRANSACT.VSAM.KSDS

  === Job 4: WAITSTEP ===
  WAIT: EXEC PGM=COBSWAIT
    SYSIN: 00003600  (36 seconds in centiseconds)

  === Job 5: OPENFIL ===
  STEP: OPCIFIL  EXEC PGM=SDSF
    Via ISFIN DD instream:
      /F CICSAWSA,'CEMT SET FIL(TRANSACT ) OPE'
      /F CICSAWSA,'CEMT SET FIL(CCXREF   ) OPE'
      /F CICSAWSA,'CEMT SET FIL(ACCTDAT  ) OPE'
      /F CICSAWSA,'CEMT SET FIL(CXACAIX  ) OPE'
      /F CICSAWSA,'CEMT SET FIL(USRSEC   ) OPE'

Performance and Batch Window Analysis

11.1 Performance Characteristics

CBACT04C processes each TCATBAL record with up to 4 VSAM I/O operations per record:

  1. READ TCATBALF (sequential — efficient; VSAM CI/CA splits buffered)
  2. READ DISCGRP (random, by composite key) — may require fallback DEFAULT read
  3. WRITE TRANSACT/SYSTRAN (sequential output — efficient)
  4. On account change only: READ ACCTFILE (random) + READ XREFFILE (random) + REWRITE ACCTFILE

The COMBTRAN step adds:

  1. SORT of two concatenated inputs (I/O bound by total record count)
  2. IDCAMS REPRO of sorted output to VSAM (sequential load)
Performance note: TCATBALF sequential read is optimal. The DISCGRP random reads are the main bottleneck in INTCALC. For large TCATBALF files, the number of DISCGRP reads equals the number of TCATBAL records (one per record). VSAM buffer tuning on DISCGRP (BUFND/BUFNI) can improve throughput. The SORT step handles the I/O-intensive merge efficiently via DFSORT’s internal buffering.

11.2 Batch Window Fit

Window ClosesWhen OPENFIL reopens CICS files
