Business Flow Analysis

1.1 Business Context

COADM01C is the Admin Menu program for the CardDemo application. It is invoked under transaction CA00 and provides the navigation hub for administrator-level functions. Only users authenticated with user type 'A' (set in CDEMO-USER-TYPE of the COMMAREA by the sign-on program COSGN00C) are routed here.

The program presents a numbered list of administrative options sourced from the COADM02Y copybook. When the administrator selects an option, the program transfers control (EXEC CICS XCTL) to the corresponding program. If the selected program name starts with 'DUMMY', an informational message is displayed instead.

  • Who uses it: System administrators / security officers
  • When: After successful sign-on with admin credentials
  • Business outcome: Route the admin to the correct user-management or DB2 maintenance function

7.2 Return Code Conventions

WS-RESP-CD and WS-REAS-CD capture the RESP and RESP2 values from EXEC CICS RECEIVE MAP, but there is no explicit evaluation of these codes in the current program. The HANDLE CONDITION PGMIDERR intercepts program-not-found errors during XCTL.

7.3 Conversation State Management

State is preserved between pseudo-conversational iterations via the CARDDEMO-COMMAREA passed on EXEC CICS RETURN TRANSID('CA00') COMMAREA(CARDDEMO-COMMAREA).

  • First entry detection: CDEMO-PGM-CONTEXT — value 0 (CDEMO-PGM-ENTER) means first entry; set to 1 (CDEMO-PGM-REENTER) after initial send.
  • Navigation tracking: CDEMO-FROM-TRANID and CDEMO-FROM-PROGRAM are set before XCTL so child programs know the calling context.
  • User identity: CDEMO-USER-ID and CDEMO-USER-TYPE flow through the COMMAREA from the sign-on program.

Security and Authorization

9.1 Transaction Security

Access to transaction CA00 is controlled at the application level rather than through RACF transaction-level security. The sign-on program COSGN00C reads the user record from the USRSEC file, checks the SEC-USR-TYPE field (defined in CSUSR01Y.cpy), and sets CDEMO-USER-TYPE in the COMMAREA.

  • If CDEMO-USER-TYPE = 'A' (CDEMO-USRTYP-ADMIN), the user is routed via XCTL to COADM01C (this program).
  • If CDEMO-USER-TYPE = 'U' (CDEMO-USRTYP-USER), the user is routed to COMEN01C (main menu) instead.

COADM01C does not re-validate the user type — it relies on the sign-on program to have performed the access check.

9.2 Data Access Authorization

No file access occurs in this program, so no data-level authorization checks are required. The downstream programs (e.g., COUSR00C) perform their own file-level access control.

9.3 Audit Trail

No explicit audit logging is performed by COADM01C. There is no EXEC CICS WRITEQ, journal writing, or TDQ logging in this program. The CICS system log (SMF) records transaction-level events.

10.2 Performance Considerations

  • Minimal resource usage: As a menu dispatcher, this transaction performs no file I/O, no database calls, and no inter-program LINK calls. Each iteration consists of a single RECEIVE MAP and a single SEND MAP.
  • Small COMMAREA: The CARDDEMO-COMMAREA structure is compact (~130 bytes), minimizing CICS storage overhead.
  • BUILD-MENU-OPTIONS loop: Iterates up to CDEMO-ADMIN-OPT-COUNT (6) times to populate menu text — negligible CPU cost.
  • XCTL (not LINK): Control transfer to child programs uses XCTL, which releases the caller's storage, keeping resource usage low.

Known Issues and Considerations

12.1 Known Issues

#IssueSeverityDetails
KI-1 No user-type re-validation Low COADM01C does not verify CDEMO-USER-TYPE = 'A' in the COMMAREA. A regular user could theoretically be routed here if the sign-on logic were bypassed.
KI-2 RESP/RESP2 from RECEIVE MAP not evaluated Low WS-RESP-CD and WS-REAS-CD are captured on the RECEIVE MAP but never checked. A MAPFAIL or other error condition would proceed to EIBAID evaluation with potentially unpredictable results.
KI-3 Hardcoded max 12 option slots in BMS map Low The BMS map defines OPTN001–OPTN012, but the CDEMO-ADMIN-OPT array in COADM02Y.cpy allows up to 9 entries. Adding more than 12 options requires BMS map changes.
KI-4 Commented-out option name in error message STRING Low Lines 153-154 and 274-275 have commented-out references to CDEMO-ADMIN-OPT-NAME(WS-OPTION). The error message does not include the specific option name that failed.
KI-5 Unused WS-USRSEC-FILE declaration Info The variable WS-USRSEC-FILE PIC X(08) VALUE 'USRSEC ' is declared but never used in the program.
