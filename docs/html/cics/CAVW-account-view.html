Business Flow Analysis

1.1 Business Context

The Account View transaction (CAVW) provides a read-only inquiry screen that allows customer service representatives and account holders to look up detailed account information. Given an 11-digit account number, the system retrieves and displays:

  • Account master data — status, balances, credit limits, key dates, and account group
  • Associated customer demographics — name, address, phone numbers, SSN, date of birth, FICO score, government-issued ID, EFT account, and primary card-holder indicator

The transaction is accessible from the Main Menu (transaction CM00, program COMEN01C) and returns to the caller on PF3. No data modification occurs; this is purely a display function.

7.2 Return Code Conventions

This program uses 88-level condition names on WS-RETURN-MSG to communicate status. The actual CICS RESP codes from file operations are evaluated via EVALUATE WS-RESP-CD with DFHRESP(NORMAL), DFHRESP(NOTFND), and OTHER branches. The INPUT-OK / INPUT-ERROR flags (WS-INPUT-FLAG) control flow between validation and data retrieval.

7.3 Conversation State Management

State is preserved across pseudo-conversational iterations via the combined COMMAREA:

  • CARDDEMO-COMMAREA (shared layout from COCOM01Y) occupies the first segment
  • WS-THIS-PROGCOMMAREA (12 bytes) is appended after CARDDEMO-COMMAREA
  • At COMMON-RETURN, both are concatenated into WS-COMMAREA (PIC X(2000)) and passed via EXEC CICS RETURN TRANSID('CAVW') COMMAREA(WS-COMMAREA)
  • On re-entry, DFHCOMMAREA is split back into CARDDEMO-COMMAREA and WS-THIS-PROGCOMMAREA
  • CDEMO-PGM-CONTEXT (0=ENTER, 1=REENTER) governs which branch of the EVALUATE in 0000-MAIN is taken

Security and Authorization

9.1 Transaction Security

The CAVW transaction does not implement its own authentication or authorization logic. Access control relies on:

  • CICS transaction-level security: The transaction ID CAVW can be secured via RACF/external security manager to restrict which user IDs may invoke it.
  • Application-level routing: The Main Menu program (COMEN01C) controls navigation. Account View is presented as a menu option to regular users (user type ‘U’). The CDEMO-USER-TYPE field in COMMAREA carries the user type established at sign-on (COSGN00C).
  • No row-level security: Any authenticated user with access to the transaction can view any account by providing its 11-digit account number.

9.2 Data Access Authorization

All three VSAM file reads (CXACAIX, ACCTDAT, CUSTDAT) are performed under the CICS region’s security context. There are no per-user data restrictions within the program. Sensitive data such as SSN is displayed on screen without masking (formatted as xxx-xx-xxxx via STRING).

9.3 Audit Trail

The program does not implement explicit audit logging. Any audit trail relies on CICS system-level journal/logging and SMF records that may be configured at the region level.
