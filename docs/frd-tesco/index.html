CardDemo batch chains Batch

One FRD per scheduler-defined (or manually triggered) batch chain of the CardDemo estate, read as the Tesco Bank Clubcard Credit Card platform. Each document is instantiated from frd-template.html and cites JCL / PROC / COBOL / scheduler source by file and line.

DRAFT
Scheduler sources disagree on the overnight daily chain. The CA-7 SCHID=030 network is CLOSEFIL → CBPAUP0J → POSTTRAN → WAITSTEP → OPENFIL (no TRANBKP anywhere in CardDemo.ca7); the Control-M DAILY-TransactionBackup folder is CLOSEFIL → TRANBKP → WAITSTEP → OPENFIL (no POSTTRAN). The two daily FRDs document each source as written and raise the reconciliation as an open question; no combined daily chain is asserted anywhere.
Third ordering for month-end interest. scripts/run_interest_calc.sh submits CLOSEFIL → INTCALC → TRANBKP → COMBTRAN → TRANIDX → OPENFIL (no WAITSTEP), which differs from the Control-M MONTHLY-InterestCalculation folder. The MonthlyInterestCalculation FRD follows Control-M and records the script as an open question.
